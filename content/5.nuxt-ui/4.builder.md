Everything under `Rollogi\NuxtUi\Builder` is an immutable, fluent value: each method returns a copy, and the tree serialises to the JSON the renderer reads. Nodes extend `Node`, which gives every one `id()`, `bind()`, `actions(...)`, `visibleWhen()` and `disabledWhen()`.

## A worked example

```php [app/Modules/Invoices/Ui/InvoiceOverviewPage.php]
public function build(UiContext $context): Node
{
    $invoice = 'sources.invoice.data';

    return Page::make('Invoice {sources.invoice.data.number}')
        ->breadcrumbs(Crumb::make('Invoices', '/invoices'), Crumb::make('{sources.invoice.data.number}'))
        ->source('invoice', Source::get('/invoices/{params.id}')->notFoundIsPage404())
        ->actions(
            OpenOverlayAction::remote('invoices.refund', ['id' => Expr::path('params.id')])
                ->label('Refund')
                ->visibleWhen(Expr::can('invoices.refund')),
        )
        ->children(
            Grid::make(3)->children(
                Stat::make('Total', Expr::path(sprintf('%s.total', $invoice)))->icon('i-lucide-receipt'),
                Stat::make('Status', Expr::path(sprintf('%s.status', $invoice))),
                Badge::make(Expr::path(sprintf('%s.status', $invoice)))->color(
                    Color::when(Expr::eq(Expr::path(sprintf('%s.status', $invoice)), 'paid'), 'success', 'warning'),
                ),
            ),
            Section::make('Danger zone')->danger()->help('Voiding cannot be undone.')->children(
                Toolbar::make()->actions(
                    HttpAction::post('/invoices/{params.id}/void')
                        ->label('Void')
                        ->color('error')
                        ->confirmWhen(true, ConfirmCopy::make('Void this invoice?')->typeToConfirm('{sources.invoice.data.number}'))
                        ->onSuccess(OnSuccess::make()->refresh('invoice')->toast(Toast::make('Invoice voided')))
                        ->visibleWhen(Expr::can('invoices.void')),
                ),
            ),
        );
}
```

Strings may contain `{...}` placeholders (`{sources.invoice.data.number}`, `{params.id}`, `{row.id}`) for the renderer to fill from its data.

## Layout

| Class | Made with | Notes |
| --- | --- | --- |
| `Page` | `Page::make($title)` | A screen root: `breadcrumbs()`, `source()`, `children()`, `actions()` |
| `Shell` | `Shell::make($title, NavLink ...$links)` | A frame around related pages: `titleAside()`, `summary(SummaryItem ...)`, `switcher(Switcher)` |
| `Section` | `Section::make($title)` | `description()`, `help()`, `danger()`, `settingsLayout()` |
| `Grid` | `Grid::make($columns)` | Lays children in columns |
| `Card` | `Card::make($title)` | `description()`, `children()` |
| `Tabs`, `TabItem` | `Tabs::make(TabItem::make($value, $label), ...)` | `defaultValue()` on the tabs, `children()` on each item |
| `Toolbar` | `Toolbar::make()` | A row of `actions()` |
| `Crumb`, `NavLink`, `SummaryItem`, `Switcher` | `make()` | Breadcrumbs, shell links, shell summary values, a shell switcher |

| Class | Made with |
| --- | --- |
| `Alert` | `Alert::make($title)`, with `description()`, `color()`, `variant()`, `icon()`, `dismissible($key)` |
| `Badge` | `Badge::make($label)` |
| `Banner`, `BannerItem` | `Banner::make(BannerItem::error($id, $title), ...)`, also `warning()`, `info()`, `success()` |
| `Chart` | `Chart::area($title)`, `Chart::line($title)` |
| `EmptyState` | `EmptyState::make($title)` |
| `ItemList` | `ItemList::make($fromPath, $itemTitle)` |
| `KeyValue`, `KeyValueRow` | `KeyValue::make(KeyValueRow::make($label, $value), ...)` |
| `Meter`, `Threshold` | `Meter::make($label, $value)`, `Threshold::at($percent, $color, $label)` |
| `Progress` | `Progress::make($value)` |
| `RelativeTime` | `RelativeTime::make($value)` |
| `Stat` | `Stat::make($label, $value)`, with `format()`, `tile()`, `sparkline()`, `tone()`, `to()` |
| `Steps` | `Steps::from($path)` |
| `Timeline` | `Timeline::from($path, $itemTitle, $itemTime)` |

Values that come from data are `Expr::path('sources.<name>.data.<field>')`. For a component the contract does not cover, `Widget::make($name, $props)` names a widget the renderer knows, with `endpoints()`, `links()`, `copy()` and `labels()` prop groups.

## Overlays

`Modal::make($id, $title)`, `Slideover::make($id, $title)` and `ConfirmDialog::make($id, $title, UiAction $onConfirm)` are roots for an overlay registered with `$registry->overlay()`, or placed inline and opened with `OpenOverlayAction::target($id)`. A modal takes `size()` and `dismissible()`, a slideover `side()`, and both their own `source()`s. Open a registered one with `OpenOverlayAction::remote($name, $params)`.

::note
A card, modal or slideover clips its overflow, so a form inside one cannot have a save bar. `children()` throws a `LogicException` if you try; leave `saveBar()` off and keep the form's buttons.
::

## Sources

A source is data the renderer fetches and the tree reads by path:

```php
Source::get('/invoices/{params.id}')
    ->poll(10_000)               // refetch every 10 seconds
    ->lazy()                     // fetch when first needed
    ->notFoundIsPage404();       // a 404 from the endpoint shows the not-found page
```

Also `fastPoll()`, `stream($channel, $event)` for a broadcast that refreshes it, `sharedWithShell()`, and `Source::local()` for a source the renderer never fetches, which cannot be lazy.

## Actions

| Class | Made with | Does |
| --- | --- | --- |
| `HttpAction` | `post()`, `put()`, `patch()`, `delete()`, `make($method, $endpoint)` | Calls your API: `bodyFromForm()`, `body()`, `multipart()`, `confirmWhen()`, `onSuccess()`, `onError()` |
| `NavigateAction` | `NavigateAction::to($path)` | Moves to an in-app path |
| `OpenUrlAction` | `OpenUrlAction::to($url)` | Opens an external URL |
| `OpenOverlayAction` | `target($nodeId)`, `remote($name, $params)` | Opens an inline or registered overlay |
| `RefreshAction` | `RefreshAction::sources(...$names)` | Refetches sources; none means all |
| `CopyAction` | `CopyAction::value($value)` | Copies to the clipboard |
| `DownloadAction` | `DownloadAction::from($endpoint)` | Downloads a file |

Every action takes `label()`, `icon()`, `color()`, `variant()`, `ariaLabel()`, `id()`, `visibleWhen()` and `disabledWhen($condition, $reason)`. `OnSuccess::make()` chains `setSource()`, `awaitChange()`, `refresh()`, `close()`, `navigate()`, `session()` and `toast(Toast::make($title))`. `ConfirmCopy::make($title)` words a confirmation, with `description()`, `confirmLabel()`, `color()` and `typeToConfirm()`.

## Forms

```php
Form::make('invoice-notes', HttpAction::patch('/invoices/{params.id}')->bodyFromForm())
    ->initial(['notes' => ''])
    ->submitLabel('Save')
    ->children(
        FieldGroup::make('Notes')->children(
            TextareaField::make('notes')->label('Notes')->optional(),
            SelectField::make('terms', Option::make('30 days', 'net30'), Option::make('60 days', 'net60'))->label('Terms'),
        ),
    );
```

Fields bind by name: `TextField`, `TextareaField`, `NumberField`, `SwitchField`, `CheckboxField`, `CheckboxGroupField`, `RadioField`, `SelectField`, `SelectMenuField`, `RepeaterField` and `FileField`. Each takes `label()`, `description()`, `placeholder()`, `hint()`, `required()` and `optional()`. A form also takes `confirmAlways()`, `confirmWhen()`, `confirmDiff()`, `readOnlyWhen()`, `resyncFrom()`, `pendingFrom()`, `searchable()` and `saveBar()`.

### Forms from Data classes

`Form::fromData($id, SomeData::class, $submit)` derives a field per property of a `spatie/laravel-data` class, so the form and the validation share one definition:

| Property | Field |
| --- | --- |
| a backed enum, or a property with an `In` rule | a select |
| `bool` | a checkbox |
| `int`, `float` | a number field, bounded by `Between`, `Min` and `Max` |
| `string` | a text field, with its length limits |

A property with no default is required; a nullable or `Optional` one is optional. Each field binds the name the Data class reads from input, so a `#[MapInputName]` or `#[MapName]` mapping is honoured, and that name is the key the helpers take:

```php
Form::fromData('invoice-settings', InvoiceSettingsData::class, $submit)
    ->labels(['dueDays' => 'Payment terms'])
    ->units(['dueDays' => 'days'])
    ->omit('internalReference')
    ->field('currency', fn (Field $field): Field => $field->hint('ISO 4217'))
    ->layout(fn (array $fields): array => [
        FieldGroup::make('Billing')->children($fields['dueDays'], $fields['currency']),
    ]);
```

`labels()`, `descriptions()`, `hints()` and `units()` (number fields only) take a map; `omit()` drops fields; `field()` replaces one, which must keep its binding; `layout()` places them, and every remaining field must be placed exactly once. A derived form places its fields with `layout()`, not `children()`.

## Expressions and conditions

`Expr` builds the conditions the renderer evaluates against its data:

```php
Expr::path('sources.invoice.data.status');
Expr::eq($left, $right);   Expr::ne(...);   Expr::gt(...);   Expr::lt(...);
Expr::in($needle, $haystack);
Expr::truthy($operand);    Expr::empty($operand);
Expr::not($condition);     Expr::and(...$conditions);   Expr::or(...$conditions);
Expr::can('invoices.void');
```

`Text::when($condition, $then, $else)` and `Color::when(...)` pick copy and colour the same way.

### `can` is folded on the server

`Expr::can()` is never sent to the renderer. Before a tree leaves the API, every `can` is answered through `UiContext::can()` and the expression is folded:

- a node or action whose `visibleWhen` folds to `false` is removed from the tree;
- a `visibleWhen` that folds to `true`, or a `disabledWhen` that folds to `false`, is dropped;
- mixed expressions keep only the parts that depend on data, so `Expr::and(Expr::can('invoices.void'), Expr::eq(...))` becomes the `eq` alone for a viewer who may void.

The tree a viewer receives therefore never names an action they may not take. To answer abilities for a specific resource, see [Configuration](/nuxt-ui/configuration#scoping-abilities-to-a-resource).
