## Rate limiters

Three named limiters are registered by Core (`Rollogi\Core\Http\RateLimiters`) and configured in its `rate-limiting.php`. Each window is one minute and each limit is overridable through an env variable.

| Limiter | Default | Env | Keyed on |
|---|---|---|---|
| `api` | 60 per minute | `RATE_LIMIT_API` | The authenticated user's id, or the IP for an unauthenticated request |
| `auth` | 10 per minute, plus 5 per minute per email | `RATE_LIMIT_AUTH`, `RATE_LIMIT_AUTH_ACCOUNT` | The client IP, and the lowercased `email` field when the request has one |
| `tenant` | 600 per minute | `RATE_LIMIT_TENANT` | The active tenant's id |

The `auth` limiter returns two limits and a request must pass both: the per-IP one stops a single client trying many accounts, the per-email one stops an attacker rotating IPs against one account. The per-email bucket is shared by every route on `throttle:auth`, so five failed logins for an address also delay a password reset for it until the window resets.

### Where each one applies

- **`api`** is appended to the `api` middleware group, so it covers every API endpoint.
- **`auth`** is applied route by route to everything that can be brute-forced or used to enumerate accounts: register, login, forgot and reset password, email verification, magic links, the two-factor challenge and enrolment, passkey ceremonies, social sign-in and linking, password change, every `/api/account` route, and invitation acceptance.
- **`tenant`** is the last middleware of `api.tenant`. Every member of a tenant shares one bucket, so one busy integration can use up the quota for everyone in that tenant.

::note
`throttle:auth` routes also count against `throttle:api`, so a request that passes the auth limit can still be refused by the general one. Keep both in mind when tuning.
::

`ResolveTenant` is placed before `ThrottleRequests` in the middleware priority list (`bootstrap/app.php`) so the tenant limiter keys on the resolved tenant rather than on nothing. Do not remove that entry.

### The 429 response

```http
HTTP/1.1 429 Too Many Requests
Content-Type: application/problem+json
Retry-After: 60
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 0

{"type":"https://api.example.com/problems/too-many-requests","title":"Too Many Requests","status":429,"detail":"Too Many Attempts.","instance":"/api/tenants/current","request_id":"...","retry_after":60}
```

### Tuning

Raise a limit through its variable. To switch the limiters off in practice during development:

```dotenv [.env]
RATE_LIMIT_API=100000
RATE_LIMIT_AUTH=100000
RATE_LIMIT_AUTH_ACCOUNT=100000
RATE_LIMIT_TENANT=100000
```

Counters live in the application's cache store (`CACHE_STORE`). With more than one app instance, use Redis so every instance shares the same counters. Behind a load balancer set `TRUSTED_PROXIES`, or every request appears to come from the proxy's address ([HTTP conventions](/kit/http#security-headers-cors-proxies-and-https)).

## Edge caching

### Fail-closed by default

Every response through the `api` group is `Cache-Control: private, no-store` unless its route explicitly opts in. `SetDefaultCacheControl` sets that directive on any response that does not already say `public`, so a CDN never caches a private or tenant-scoped answer.

::warning
Routes outside the `api` group are not covered: Passport's `oauth/*` routes, the framework's `storage/*` route, `/up`, and Scramble's `/docs/*`. Rely on a Cloudflare bypass rule for those (below).
::

### Opting a route in

Apply the `cache.public` alias to a public, non-personalised `GET` route:

```php
Route::get('/status', StatusController::class)->middleware('cache.public:30');
```

The argument is the browser `max-age` in seconds; without it `CACHE_BROWSER_MAX_AGE` applies. `CachePublic` acts only on `GET` and `HEAD` responses with status `200` that set no cookies, and sets:

| Header | Value |
|---|---|
| `Cache-Control` | `public, max-age=<browser>, s-maxage=<cdn>` |
| `CDN-Cache-Control` | `public, max-age=<cdn>`, the edge TTL, separate from the browser's |
| `Vary` | `Accept` |
| `ETag` | SHA-1 of the body, so `If-None-Match` gets a `304` |
| `Cache-Tag` | `<prefix>,<path>`, for example `api,docs/api.json` |

::caution
Never put `cache.public` on an authenticated route or a route that starts a session or sets cookies. `CachePublic` refuses to mark a response public when it carries a `Set-Cookie` header, but that guard only sees cookies: nothing stops a bearer-authenticated JSON response from being marked public if you put the middleware on its route.
::

Public routes vary only on `Accept`. `Vary: Authorization` is deliberately unused: private routes are never publicly cached, and varying on the token would create one cache entry per token.

### What the kit caches

| Route | How |
|---|---|
| `/docs/api` (Scramble UI and JSON, `local` only) | `cache.public` is in `config/scramble.php`'s `middleware`, without an argument, so the config defaults apply. The `web` group is left out so the docs start no session and set no cookies |
| `/up` | A static framework route; cache it with a Cloudflare rule if you want to |

### Cloudflare cache rules

1. **Respect origin headers.** A cache rule on your API hostname with *Cache eligibility* "Eligible for cache" and *Edge TTL* "Respect origin", so Cloudflare honours `CDN-Cache-Control` (or `s-maxage`).
2. **Bypass when authenticated.** A higher-priority rule matching `http.request.headers["authorization"] exists` or `http.cookie ne ""`, set to *Bypass cache*. This is the backstop if a route ever emits `public` by mistake.

::warning
Never enable "Cache Everything" on the API host without the bypass rule. It overrides `private, no-store` and would cache private responses.
::

Cloudflare Enterprise can purge by tag (`{"tags":["api"]}` against the zone's `purge_cache` endpoint); every plan can purge single URLs (`{"files":["https://api.example.com/docs/api.json"]}`).

## Configuration

| Env | Config key | Default | Meaning |
|---|---|---|---|
| `RATE_LIMIT_API` | `rate-limiting.api.max` | `60` | Requests per minute per user or IP |
| `RATE_LIMIT_AUTH` | `rate-limiting.auth.max` | `10` | Requests per minute per IP on `throttle:auth` |
| `RATE_LIMIT_AUTH_ACCOUNT` | `rate-limiting.auth_account.max` | `5` | Requests per minute per email on `throttle:auth` |
| `RATE_LIMIT_TENANT` | `rate-limiting.tenant.max` | `600` | Requests per minute per tenant |
| `CACHE_DEFAULT_DIRECTIVE` | `cache-control.default` | `private, no-store` | Directive for responses that did not opt in |
| `CACHE_BROWSER_MAX_AGE` | `cache-control.public.browser_max_age` | `60` | Browser TTL for `cache.public` routes |
| `CACHE_CDN_MAX_AGE` | `cache-control.public.cdn_max_age` | `300` | Edge TTL for `cache.public` routes |
| `CACHE_TAG_PREFIX` | `cache-control.cache_tag_prefix` | `api` | First segment of `Cache-Tag` |
