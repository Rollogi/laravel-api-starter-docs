The starter kit is a Laravel 13 project skeleton for an API-only, single-database multi-tenant SaaS. [rollogi/core](/core) supplies the infrastructure; the kit adds the modules a SaaS needs on day one and the conventions every new module follows.

## Start here

- [Architecture](/kit/architecture): how the kit is laid out, how modules are discovered, and where Core ends.
- [Use-cases](/kit/use-cases): the Data, Controller, Service, Action, Policy flow and the generators that write it.
- [Multi-tenancy](/kit/multi-tenancy): the `api.tenant` group, the active tenant, and per-tenant roles.

## The shipped modules

| Module | What it does | Read |
| --- | --- | --- |
| `Tenants` | Tenant lifecycle and settings, members, invitations, roles, API keys, the activity stream and the `tenant:*` commands | [Tenants](/kit/tenants), [Roles and API keys](/kit/roles-and-api-keys) |
| `Auth` | Registration, Passport sign-in, passwords, sessions, magic links, two-factor, passkeys and social sign-in | [Authentication](/kit/authentication), [Two-factor and passkeys](/kit/two-factor-and-passkeys), [Social sign-in](/kit/social-sign-in) |
| `Account` | Self-service on the caller's own account: rename, email change, deletion and export | [Account](/kit/account) |
| `Notifications` | Push devices, notification preferences and the in-app inbox | [Notifications](/kit/notifications) |
| `Webhooks` | Per-tenant outbound webhook subscriptions, signed deliveries, retries and replay | [Webhooks](/kit/webhooks) |

## Conventions and operations

- [HTTP conventions](/kit/http) and [rate limiting and caching](/kit/rate-limiting-and-caching): problems, pagination, filtering, versioning and the edge.
- [Feature toggles](/kit/feature-toggles): every capability has a key that can be switched off globally or per tenant.
- [Auditing](/kit/auditing): service calls and model changes, both carrying the tenant and request id.
- [Deployment](/kit/deployment) and [testing](/kit/testing): the production image, Octane, and the suite on three databases.

::tip
The optional packages plug in the same way as the kit's own modules: see [rollogi/billing](/billing) and [rollogi/nuxt-ui](/nuxt-ui).
::
